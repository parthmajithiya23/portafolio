# Parth Majithiya Portfolio

Static React + Vite portfolio. No backend or admin panel.

```bash
cd frontend
npm install
npm run dev
npm run build
```

- Projects: edit `frontend/src/data/projects.js`.
- Contact form: sends email via Web3Forms (free, 250/month).
  Get a key at web3forms.com and paste it in `frontend/src/pages/Contact.jsx` (`WEB3FORMS_KEY`).
